# 书灯 0.1.2

iOS 原生版，构建号 3。

## 本次更新

- 精简导航与设置，底部顺序为「书架 / 笔记 / 对话 / 我的」，去掉对话页重复搜索入口。
- 改善大字号布局、书封点击区域和索引重试按钮可读性。
- 笔记草稿自动保留，退出未保存修改时确认；明确保存、放弃和恢复状态。
- 阅读报告解读保留到本地，区间隔离；生成和保存失败可重试。
- 翻译错误与译文分开显示，失败保留原文并支持重试。
- 正文搜索和智能搜索提供加载、空结果、失败及恢复提示；索引故障显示书名并支持同页重试。
- 统一阅读时长显示，保留 Markdown 段落、标题和列表层级。

## 发布验证

- 169 项报告、翻译、笔记、搜索及索引状态检查通过。
- 10 项 Markdown 测试通过。
- iPhone Release 编译、arm64 架构及开发签名校验通过；阅读器、内核及 LICENSE 与当前构建资源逐字节一致。
- 模拟器构建启动通过；4 项实际 UI 断言通过：4 本合成样书可见、底部标签顺序正确、「智能搜索」入口存在、关于页显示 0.1.2。
- 接手阶段的报告/翻译同页恢复使用受控测试端点与合成回包，仅证明客户端恢复，不作为线上 AI 服务效果证据。

## 验证边界

书内搜索异常恢复的真实 UI、快速输入、中文系统索引成功、索引中断/取消、多书失败、VoiceOver、其他屏幕与真机升级未验证。键盘相关 UI 与朗读按要求跳过。
